# 🔔 알림으로 답장 (예비 기능)

접근성 없이 동작하는 예비 길입니다. 구글이 접근성 사용을 거절하거나("더 좁은 권한을 쓰라"), 카카오가 화면 자동 입력을 문제 삼을 때 이 길로 바꿀 수 있습니다.
지금은 **기본으로 꺼져 있고**, 숨은 설정에서 켜야 동작합니다. 기존 🎤 버튼(접근성) 기능은 그대로입니다.

## 어떻게 동작하나
1. 카톡 메시지 알림이 오면, 앱이 그 알림의 **'답장' 칸**을 기억합니다 (휴대폰 메모리에만, 저장 안 함).
2. 조용한 알림 **"💬 방 이름 — 마지막 메시지 [🎤 말로 답장]"**을 띄웁니다 (소리 없음).
3. 누르면 카드가 열려 바로 듣습니다 → 알림에 보이던 최근 메시지를 맥락으로 AI가 다듬음.
4. 사용자가 확인하면(확인 후 / 3초 뒤 / 듣고 확인) **카톡 알림의 답장 칸으로** 보냅니다.
5. 카톡 알림이 사라지면(읽음 등) 기억도 지웁니다.

| | 🎤 버튼 (접근성) | 🔔 알림으로 답장 |
|---|---|---|
| 필요한 권한 | 접근성 (구글 신고·심사) | 알림 접근 (심사 신고서 없음) |
| 대화 맥락 | 화면에 보이는 대화 | 알림에 담긴 최근 메시지(보통 몇 개) |
| 보내는 방법 | 카톡 입력창에 넣고 전송 버튼 누름 | 카톡 알림의 '답장' 칸 (카톡이 공식 제공) |
| 언제 쓸 수 있나 | 카톡 대화방을 보고 있을 때 | 새 메시지 알림이 와 있을 때 |
| 카카오 '자동화' 논란 | 있음 | 거의 없음 (알림 답장은 안드로이드 표준 기능) |

## 켜는 법 (폰에서 시험)
1. 앱 제목 '말로 답장'을 길게 눌러 자세한 설정 → **🔔 알림으로 답장 → 켜기** → 안내에 **동의하고 켜기**
2. 알림 표시 허용을 물으면 **허용**
3. 알림 접근 설정 화면에서 **'말로 답장' 허용**
4. 다른 폰에서 카톡을 보내 보고 → 알림 아래 **'🎤 말로 답장'** 확인 → 눌러서 말하기 → 보내지는지

## 정식으로 이 길을 쓰게 되면 고칠 것
- 개인정보처리방침·데이터 보안: 알림 접근으로 카톡 알림의 방 이름·최근 메시지를 읽는다는 내용 추가 (켠 사람만 해당)
- 스토어 설명에 '알림으로 답장' 설명 추가
- 접근성 기능을 아예 빼면: 접근성 신고서 불필요, 🎤 떠 있는 버튼 대신 알림이 입구
