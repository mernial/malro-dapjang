# 유료 판매용 중계 서버 설계 (사지 않고 계획만)

정리일: 2026-11-05 · 판매를 시작하기로 하면 이 순서대로 만듭니다. **지금은 아무것도 사지 않았습니다.**

## 1. 왜 서버가 필요한가

지금은 사용자 폰마다 Claude API 키가 들어 있습니다. 판매판에서는 다음이 필요합니다.
- 일반 사용자는 키를 만들 수 없습니다. → **키는 서버에만** 둡니다.
- 앱 안에 키를 넣으면 누구나 꺼내 쓸 수 있습니다. → **요금 폭탄 위험**이 생깁니다.
- 구독한 사람만, 정해진 만큼만 쓰게 해야 합니다. → 서버가 **구독 확인과 사용량 한도**를 맡습니다.

## 2. 흐름

```
폰(말로 답장) ──① 구글 로그인 토큰 + 요청──▶ 중계 서버 ──② 구독 확인(구글 플레이 API)
                                               │──③ 이번 달 사용량 확인·더하기(DB)
                                               └──④ Claude API (서버의 키) ──▶ 답 ──▶ 폰
```

- 앱 쪽 변경: `core/Assistant`를 지키는 **서버판 하나**만 만들어 `ClaudeProvider`에서 바꿔 끼웁니다. 1.111에서 이 자리를 미리 만들어 두었습니다. 화면 코드는 그대로입니다.
- 서버는 AI에 보낼 글을 **저장하지 않고** 넘기기만 합니다. 횟수와 토큰 수만 셉니다. 그래서 개인정보처리방침의 국외 이전 내용이 크게 바뀌지 않습니다.

## 3. 후보 비교 (월 비용은 2026년 말 기준 추정, 시작 전 다시 확인)

| 후보 | 월 비용 | 장점 | 단점 |
|---|---|---|---|
| **Cloudflare Workers + D1** (추천) | 무료 → 유료 $5(약 7,000원) | 싸고 빠름, 서버 관리 없음, 한국에서도 빠름, DB 포함 | 구글 API 서명(JWT)을 직접 짜야 함 |
| Firebase Functions + Firestore | 사용량만큼(작으면 거의 0원) | 구글 로그인·플레이와 잘 맞음 | 요금제(Blaze)에 카드 등록 필요, 많이 쓰면 비용 예측이 어려움 |
| Supabase Edge Functions | 무료 → $25 | DB·로그인 화면 기본 제공 | 유료 단계가 비쌈 |
| AWS Lambda | 사용량만큼 | 무엇이든 가능 | 설정이 복잡함 |

**추천: Cloudflare Workers.** 사용자 수백 명까지는 무료 또는 $5로 충분하고, 손볼 서버가 없습니다.

## 4. 만들 것 (판매 결정 후, 대략 1~2주)

1. **로그인:** 앱에서 구글 계정으로 로그인(Credential Manager). 서버가 구글 ID 토큰을 확인합니다.
2. **구독 상품:** Play Console에서 구독 상품(월·연, 무료 체험 14일)을 만들고, 앱에 Play Billing Library를 넣습니다.
3. **구독 확인:** 서버가 Google Play Developer API(`purchases.subscriptionsv2`)로 확인합니다. 해지·갱신은 실시간 알림(RTDN, Pub/Sub)으로 받습니다.
4. **사용량 한도:** 사용자별로 한 달 횟수와 토큰을 DB에 셉니다. 공정 사용 한도는 `pricing.md`에 있습니다.
5. **중계:** 서버가 Claude API를 부릅니다(모델 `claude-haiku-5-5`, 지금 앱과 같은 프롬프트). 답만 돌려줍니다.
6. **안전장치:** 사용자별 분당 요청 제한, Claude Console의 월 사용 한도와 알림.
7. **앱 정리:** 판매판에서는 'API 키 넣기'와 '가족에게 설정 보내기'를 빼고 '구독하기' 화면을 넣습니다. 가족·테스트용 직접 키 방식은 숨은 설정에 남길지 그때 정합니다.

## 5. 판매 결정 때 정할 것

- 요금(월·연), 무료 체험 기간, 한도 → `pricing.md`
- 가족 묶음 요금을 둘지
- 지금 쓰시는 분들(가족·테스터)을 무료로 둘지, 초대 코드로 처리할지
