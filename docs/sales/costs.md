| 사용자 | 모두 '가끔' | 모두 '보통' | 모두 '많이' |

| 100명 | 약 18,000원 | 약 35,000원 | 약 97,000원 |
| 1,000명 | 약 18만 원 | 약 35만 원 | 약 97만 원 |

| 10,000명 | 약 181만 원 | 약 351만 원 | 약 971만 원 |

- 1,000명까지는 서버가 무료. 5,000명부터 서버 월 7,000원이 더해짐(표에 포함).
- 실제로는 섞여 쓰므로 대개 **'가끔'과 '보통' 사이** (1인당 월 200~350원)로 보면 됨.

## 4. 안전장치 (예상 밖 지출 막기)

- **하루 전체 한도 5,000번** (`GLOBAL_DAILY_LIMIT`): 최악이라도 하루 약 1.4만 원, 한 달 약 40만 원을 넘지 않음.
  대신 '보통' 사용자가 **약 400명을 넘으면 이 한도에 걸림** → 사용자가 늘면 한도를 올려야 함.
- 폰 한 대 하루 150번 (`DEVICE_DAILY_LIMIT`).
- Anthropic 콘솔의 월 사용 한도 (신부님이 설정): 마지막 방어선.
