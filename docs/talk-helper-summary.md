## 1. 무엇을 만들었나

카카오톡 대화방에서 떠 있는 **🎤 버튼**(검은 원·금테)을 누르고 편하게 말하면, AI가 뜻을 알아듣고 고른 말투로 다듬어 **카톡으로 보내 주는** 안드로이드 앱입니다. 지난 대화에서 원하는 내용을 찾아 정리해 주는 기능도 있습니다.

| 구분 | 직접 설치판 (예전) | 플레이 스토어판 (지금 쓰는 것) |
|---|---|---|
| 앱 이름 | 카톡 도우미 (노란 아이콘) | **말로 답장** |
| 받는 곳 | GitHub 링크 (APK) | 플레이 **내부 테스트** |
| 업데이트 | 앱 안 "🔔 새 버전" 버튼 | 앱 첫 화면 **업데이트 배너 → 플레이 스토어** |
| 패키지 이름 | `kr.yunho.talkhelper` (둘 다 같음, 서명은 다름 → **한 폰에 하나만**. 예전 판이 남아 있으면 플레이판 다운로드 실패) | |

**쓰는 법**
- 🎤 **한 번 누르기** → 저장된 말투로 바로 듣기 → 말하고 끝에 **"보내 줘" / "끝"**
- 🎤 **꾹 누르기** → 진동 + 동그라미 메뉴: 🙏 정중하게 · 😊 친구처럼 · 💼 업무 연락 · 🤗 자녀에게 · 🪞 내 말투 · 🔎 찾기 · ⚙️ 설정
  - 동그라미를 꾹 누른 채 끌면 **순서 바꾸기** (기억됨)
  - ⚙️ 설정: 보내는 방식, 찾은 내용 읽어 주기, 🎤 버튼 끄기

**주요 기능**
- 보내는 방식: **바로** · **3초 뒤** · **확인 후** · **듣고 확인**(읽어 주고 "보내/다시/취소"로 대답)
- 말투: 정중하게(서로 존중하는 해요체, 굽신거리지 않게), **내 말투**(그 방에서 내가 쓰던 말투를 예시로 따라 함)
- 호칭 보정: 말하지 않은 호칭(예: 내 신분인 '신부님')은 빼고, 말한 호칭(자매님 등)은 그대로
- AI가 생각한 내용이 새어 나가지 않게 답장은 정해진 형식으로만 받음
- **대화에서 찾기**: 그 방에서 내보낸 대화가 없으면 "이 방 대화를 내보낼까요?" → **직접 내보내기**(카톡 ☰ → ⚙ → 대화 내용 내보내기 → '대화에서 찾기') → 휴대폰에만 저장 → 카톡 위 작은 카드에 **결론·진행·결정·미정·근거**로 정리 → **📋 찾을 말 복사 / 🚩 / 닫기**
  - 내보낸 대화는 앱이 붙인 **고유 번호**로 저장하고 그 카톡 방과 짝지음 → 다음부터 그 방에서 물으면 그 대화에서만 찾음 (다른 방 대화는 쓰지 않음, 이름 같은 방도 안 섞임)
  - 플레이판은 정책 때문에 카톡 메뉴 자동 누르기·대화방 자동 넘기기·'바로 보내기'를 껐음 (`STORE_SAFE`, `docs/launch-risks.md`)
  - 한 번 내보낸 방은 화면의 대화 내용으로 알아봐서 다시 묻지 않음
  - 사진도 함께 내보내 두면 대화 흐름으로 사진을 찾아 보여 줌 (사진은 휴대폰 밖으로 안 나감)
- 앱 첫 화면: 켜기/끄기, 사용법 두 줄, 보내는 방식, 찾은 내용 읽어 주기
- 숨은 설정: 앱 제목 **"말로 답장"을 길게 누르기** → API 키·이름·역할, 대화에서 찾기(대화·사진 저장), 가족에게 설정 보내기, 문제 기록, **이번 달 사용량**, **저장한 대화·기록 모두 지우기**
- 모든 화면 아래: **개인정보처리방침 보기**, 문의 메일
- 🚩 이상한 AI 답장 알리기 (사용자가 확인 후 메일로)
- 받아쓰기: 휴대폰 기본 음성 인식(무료). 고급 받아쓰기(Whisper)는 반응이 느려 뺐음
- AI 모델: 다듬기·찾기 모두 Claude **Haiku 5.5** (Sonnet은 쓰지 않음)

## 5. 업데이트가 흘러가는 길

1. 제가(Claude) 코드를 고쳐 GitHub에 올립니다.
2. GitHub가 자동으로 테스트하고, **APK(직접 설치판)와 AAB(플레이판)**를 만들어 Releases에 올립니다. 버전 번호는 자동으로 올라갑니다.
3. 직접 설치판: 앱을 열면 **"🔔 새 버전" → 지금 업데이트**
4. 플레이판:
   - 서비스 계정 키를 등록했다면 → **내부 테스트에 자동 업로드** → 폰이 **자동 업데이트**
   - 등록 전이라면 → Play Console → 내부 테스트 → 새 버전 만들기 → AAB 업로드 → 출시

## 6. 설치 요약 (플레이 내부 테스트)

1. Play Console → 말로 답장 → 테스트 → 내부 테스트 → **테스터** 탭 → 이메일 목록에 Gmail 추가 → 저장
2. **설치 안내 페이지** 링크를 카톡으로 보냄 (카톡에서 눌러도 크롬으로 넘어가 테스터 참여 화면이 자동으로 열림)
3. 폰: **테스터 되기** → **Download test app / Google Play에서 다운로드** → **설치**
4. 앱 열기 → 접근성 켜기 → 마이크 허용 → 끝 (2026-11-07부터 중계 서버라 설정 코드 필요 없음. 예전 설정 코드는 숨은 설정에 예비로 남음)
5. 카톡 → 🎤 → 말하고 **"보내 줘"**

**설치가 안 될 때 (어머니 S26에서 겪은 것)**
- 링크를 누르면 플레이 스토어 앱이 가로채 "항목을 찾을 수 없습니다" → 테스터 참여는 **크롬**에서 (설치 안내 페이지가 자동으로 처리)
- 테스터 등록 후 "다운로드할 수 없습니다" → **예전 '카톡 도우미'가 남아 있음**(보안 폴더·듀얼 앱 포함) 또는 플레이 스토어 데이터 꼬임 → 예전 앱 삭제, 플레이 스토어 데이터 삭제 후 재시작
- 부모님이 하기 어려우면 TeamViewer QuickSupport로 원격 설치

## 8. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 설치 시 "Play 프로텍트 앱 차단됨" (직접 설치판) | Play 스토어 → 프로필 → Play 프로텍트 → ⚙ → 앱 검사 끄기 → 설치 → 다시 켜기 |
| 접근성이 회색 "제한된 설정" (직접 설치판) | 앱 정보 → ⋮ → 제한된 설정 허용 (⋮가 없으면 자동 차단기 끄기) |
| "API 키가 올바르지 않습니다" | 키 만료·삭제 → 새 키 만들어 앱에 넣고 '가족에게 설정 보내기' 다시 |
| 노란 도우미 버튼이 안 보임 | 앱 열기 → 준비 1/3 접근성 다시 켜기 |
| 보내기가 안 됨 | 앱 첫 화면 맨 아래 '마지막 보내기 기록' 캡처 → Claude에게 전달 |
| 플레이에서 "앱을 찾을 수 없음" | 테스터 참여를 크롬에서(설치 안내 페이지), 플레이 스토어 계정이 테스터 Gmail인지 확인 |
| "다운로드할 수 없습니다" | 예전 '카톡 도우미' 삭제(보안 폴더도 확인), 플레이 스토어 데이터 삭제 후 재시작 |
| 찾기에서 내보내기가 멈춤 | 덮개에 나온 순서대로 직접 내보내기. 숨은 설정의 '대화 내보내기·찾기 기록' 캡처 |
| 답장에 이상한 설명이 붙음 | 업데이트(1.59 이후 막음). 보내는 방식을 '확인 후'로 |
