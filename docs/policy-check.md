# 정책 점검 (기능을 바꿀 때마다)

사용자 요청: 카카오·구글 정책에 걸리거나 심사에 안 될 것 같은 것은 **업데이트 전에** 알릴 것.

## 기준
**카카오** (운영정책·통합서비스약관, 2차 답변 2026-11-10)
- 카카오톡을 **대신 누르거나 넘기거나 전송**하지 않기 (자동 조작 불허)
- 카카오톡 **화면 내용을 읽지 않기** (키보드판 목표)
- 카카오 서버 접속·앱 변조 없음, 대량·자동 발송 없음
- 카카오톡 공식 기능(대화 내보내기)으로 사용자가 직접 내보낸 파일만 사용
- 이름·아이콘에 '카톡' 상표 안 쓰기, "카카오와 관련 없는 독립 앱" 표기

**구글 플레이**
- 접근성: 쓰면 공개·동의, 신고서와 실제 동작 일치 (키보드판에서는 접근성 없앨 예정)
- 키보드(IME): 입력한 글을 모으거나 밖으로 보내지 않기. 🎤로 말한 내용과 찾기 질문만 AI로 (데이터 보안 양식 '메시지'로 신고)
- AI 생성 콘텐츠: 이상한 결과 신고(🚩) 수단
- 데이터 보안 양식·개인정보처리방침이 실제와 같을 것
- 새 권한은 꼭 필요할 때만
