# 🚩 이상한 답장 알림용 구글 설문지 만들기 (5분)

구글 정책: AI가 만든 글을 **앱을 나가지 않고 개발자에게** 신고할 수 있어야 합니다.
서버 없이 하려고, 앱이 🚩 알림을 **구글 설문지**로 보냅니다. 답은 신부님 구글 계정에 쌓입니다.

## 1. 설문지 만들기 (컴퓨터에서)

1. https://forms.google.com → **빈 양식(+)**
2. 제목: `말로 답장 - 이상한 답장 알림`
3. 질문 4개를 **이 순서대로** 만듭니다. 종류는 모두 **장문형**(긴 답변), **필수는 끔**.
   1. `무엇이 이상했나요`
   2. `말한 내용`
   3. `AI가 만든 글`
   4. `앱 버전`
4. 위쪽 **설정** 탭에서
   - **응답 → 이메일 주소 수집: 수집 안함**
   - **응답 → 응답 횟수 1회로 제한: 끔** (켜면 로그인이 필요해져 앱이 못 보냄)
5. (선택) **응답** 탭 → **Sheets에 연결**하면 구글 시트로 모아 볼 수 있습니다.

## 2. 저에게 보내 주실 것

1. 오른쪽 위 **⋮ → 미리 채워진 링크 가져오기**
2. 네 칸에 아무 글자나 넣습니다 (예: `가`, `나`, `다`, `라`)
3. 아래 **링크 가져오기 → 링크 복사**
4. 그 링크를 이 대화에 붙여 넣어 주세요.

링크에 설문지 번호와 칸 번호(`entry.123456…`)가 들어 있습니다. 비밀 값이 아니라 붙여 넣으셔도 됩니다.
제가 앱에 넣고(`App.kt`의 `REPORT_FORM_URL`, `REPORT_FORM_FIELDS`) 빌드한 뒤, 시험 알림이 설문지에 도착하는지 함께 확인합니다.

## 참고

- 설문지 주소가 들어가기 전에는 🚩가 **휴대폰에만 기록**됩니다(자세한 설정에서 볼 수 있음).
- 개인정보처리방침에 "🚩를 누르면 구글 설문지로 운영자에게 전달"을 추가해야 합니다. 설문지가 완성되면 제가 고칩니다.
