# 스토어 스크린샷 · 심사 영상 찍는 법

정식 출시 신청 전에 필요합니다. 신부님 폰(최신 버전 '말로 답장')으로 찍으시면 됩니다.

> **찍기 전에:** 실제 지인 이름과 대화가 보이지 않게 **시험용 카톡방**을 하나 만드세요.
> 예: 가족 한 분과 '말로 답장 시험' 방을 만들어 "내일 성당 몇 시에 가요?" 같은 평범한 대화를 몇 줄 나눠 둡니다.

## 1. 스크린샷 (휴대폰, 최소 2장 · 권장 4장)

전원 버튼 + 소리 줄이기 버튼을 함께 누르면 찍힙니다. 세로 화면으로 찍습니다.

| 순서 | 화면 | 찍는 방법 |
|---|---|---|
| ① | **카톡 위 🎤 버튼** | 시험용 카톡방을 열고, 오른쪽에 🎤 버튼이 보일 때 |
| ② | **다듬은 답장 카드** | 🎤 누르고 "내일 열 시에 간다고 보내 줘"라고 말한 뒤, 다듬은 문장과 '3초 뒤 보내기 / 취소'가 보일 때 |
| ③ | **말투 고르기** | 🎤를 꾹 눌러 동그라미 메뉴(정중하게·친구처럼·업무 연락…)가 펼쳐졌을 때 |
| ④ | **대화에서 찾기** | 🔎로 "모임 시간 언제로 정했지?"라고 물어 정리된 답이 보일 때 |

- 다 찍으면 **iCloud `말로답장` 폴더**에 넣어 주세요. 제가 `docs/play-store/screenshots/`에 넣고 Play Console 등록 순서를 안내해 드립니다.
- 상태 표시줄(시간·배터리)은 그대로 둬도 됩니다.

## 2. 접근성 심사 영상 (필수, 30초~1분)

화면 녹화: 위에서 두 번 쓸어내림 → **화면 녹화** → 소리 '없음' 또는 '미디어 소리'.

1. **'말로 답장' 앱 첫 화면** → '설정 열기'를 눌러 **「접근성 권한 사용 안내」 창**이 보이게 (글이 길면 **천천히 스크롤**해서 전부 보이게)
   - 먼저 **'동의 안 함'**을 눌러 아무 일도 안 생기는 장면 → 다시 '설정 열기'를 눌러 **안내 창이 또 뜨는 장면** (구글이 요구함)
   - 그다음 **동의하고 켜기**
   - 안내 창은 한 번 동의하면 다시 안 뜹니다. 이미 동의했다면 찍기 전에 **휴대폰 설정 → 애플리케이션 → 말로 답장 → 저장공간 → 데이터 삭제**를 하세요. 그 뒤 앱을 열어 설정 코드로 다시 준비하고, 안내 창 장면부터 찍습니다.
2. 휴대폰 **접근성 설정에서 '말로 답장' 켜기**
3. **시험용 카톡방** → 🎤 → "내일 회의 세 시로 하자고 보내 줘"
4. 다듬은 문장과 **3초 카운트다운·취소 버튼**이 보이는 장면 → 전송되는 장면
5. (선택) 한 번은 **취소**를 눌러 보내지지 않는 장면도 넣으면 좋습니다

녹화한 영상은 **유튜브에 '일부 공개(미등록)'로 올리고** 링크를 Play Console 접근성 신고서에 넣습니다. 올리는 법이 어려우시면 영상을 iCloud에 넣어 주시면 안내해 드립니다.

## 3. 그 다음

- 스크린샷 → Play Console → 스토어 등록정보 → 휴대전화 스크린샷
- 영상 링크 → 앱 콘텐츠 → 민감한 권한 및 API → 접근성 API
- 글(설명·데이터 보안·신고서 문구)은 `docs/play-store/README.md`에 준비돼 있습니다.
