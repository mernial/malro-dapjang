## F. 프로덕션 액세스 신청 (14일 뒤 대시보드에 열림) — 답안 초안

| 질문 | 답 (초안, 실제 경험으로 고쳐 쓰기) |
|---|---|
| 테스터를 어떻게 모았나요? | 본당 신자와 가족·지인에게 카카오톡으로 안내해 모집했습니다. 자판 입력이 불편한 50~80대가 많습니다. |
| 테스터 참여는 어땠나요? | 테스터들이 매일 카카오톡 답장에 앱을 썼고, 🎤로 말한 내용을 다듬어 보내는 기능을 주로 썼습니다. (실제 사용량은 숨은 설정의 '이번 달 사용량'으로 확인) |
| 받은 피드백 요약 | (🚩 설문지 응답과 카톡 의견을 보고 적기. 예: 받아쓰기가 끊기는 문제, 말투가 지나치게 공손하다는 의견) |
| 피드백으로 무엇을 고쳤나요? | (테스트 기간에 고친 것 적기. 예: 다른 방 대화를 찾던 문제 수정, 기본 보내기 방식을 '확인 후'로) |
| 누구를 위한 앱인가요? | 휴대폰 자판으로 글 쓰기가 어려운 어르신과 바쁜 분이, 말로 카카오톡 답장을 정중하게 보내도록 돕는 앱입니다. |
| 출시 준비가 됐다고 보는 이유 | 14일 동안 12명 이상이 실제로 쓰며 주요 문제를 고쳤고, 보내기 전에 항상 확인·취소할 수 있으며, 개인정보 처리와 접근성 사용을 앱 안에서 안내하고 동의를 받습니다. |
