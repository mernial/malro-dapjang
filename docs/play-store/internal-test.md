# 내부 테스트로 부모님께 배포하기

구글 심사 없이, 명단에 넣은 사람만 플레이 스토어에서 설치할 수 있습니다. 최대 100명까지 가능합니다.

## A. 신부님 (Play Console, 컴퓨터 권장)

**준비물:** 부모님의 **Gmail 주소**(부모님 폰의 플레이 스토어에 로그인된 계정)

1. **앱 파일 받기**
   컴퓨터에서 아래 주소를 열어 `talk-helper-play.aab`를 받습니다.
   https://github.com/mernial/malro-dapjang/releases/download/talk-helper/talk-helper-play.aab
2. **앱 만들기**
   Play Console → **앱 만들기** → 이름 `말로 답장` · 기본 언어 `한국어` · **앱** · **무료** → 선언 체크 → **앱 만들기**
3. **테스터 명단 만들기**
   왼쪽 메뉴 **테스트 및 출시 → 테스트 → 내부 테스트** → **테스터** 탭 → **이메일 목록 만들기**
   - 목록 이름: `가족`
   - 부모님 Gmail 주소 입력 (신부님 Gmail도 함께 넣으면 직접 확인할 수 있습니다)
   - **변경사항 저장**
   - **의견 URL 또는 이메일**: `mernial@naver.com`
4. **앱 올리기**
   같은 화면 오른쪽 위 **새 버전 만들기**
   - **Play 앱 서명**: "Google에서 앱 서명 키 관리" 그대로 → **계속**
   - **App Bundle 업로드** → 1번에서 받은 `talk-helper-play.aab`
   - 출시 노트: `가족용 첫 버전입니다.`
   - **다음** → **저장** → **내부 테스트로 출시 시작**
   - 이때 개인정보처리방침이나 접근성 신고 같은 항목을 채우라고 나오면, `docs/play-store/README.md`의 내용을 그대로 넣으세요.
5. **참여 링크 복사**
   **테스터** 탭 맨 아래 **"테스터 참여 방법" → 링크 복사**
   → 부모님께 카톡으로 보냅니다.

## B. 부모님 폰

1. **예전 앱 지우기**: 노란 '카톡 도우미'가 깔려 있으면 길게 눌러 **삭제**합니다.
2. **계정 확인**: Play 스토어 → 오른쪽 위 프로필 사진을 누르고, 명단에 넣은 **그 Gmail**인지 확인합니다.
3. **설치**: 카톡으로 받은 링크 → **"테스터 되기"** → **"Google Play에서 다운로드"** → **설치**
   - "앱을 찾을 수 없음"이 나오면 몇 분에서 몇 시간 뒤에 다시 눌러 주세요. 첫 배포는 늦게 열릴 수 있습니다.
4. **'말로 답장' 앱 열기 → 노란 버튼 차례로**
   - **준비 1/3**: 설정 열기 → 안내 창 **"동의하고 켜기"** → '말로 답장' **켜기** → **허용** → 뒤로 가기(◁)
   - **준비 2/3**: 마이크 허용하기 → **"앱 사용 중에만 허용"**
   - **준비 3/3**: 신부님이 보낸 **[카톡 도우미 설정]** 메시지를 **길게 눌러 복사** → 앱을 열면 끝
5. **써 보기**: 카톡 대화방 → 화면 오른쪽 **노란 '도우미' 버튼** → 말하고 끝에 **"보내 줘"** (앱 아이콘은 초록색이지만, 카톡 위 버튼은 노란색 그대로입니다)

## C. 업데이트할 때

1. 앱을 고치면 GitHub가 새 `talk-helper-play.aab`를 만듭니다. 같은 주소에 덮어써집니다.
2. 신부님이 Play Console → 내부 테스트 → **새 버전 만들기** → 새 파일을 올리고 → **출시**합니다.
3. 부모님 폰은 **플레이 스토어가 알아서 업데이트**합니다.
