# 「말로 답장」 개인정보처리방침 (새 초안, 2026-11-05)

> **참고:** 확인해 보니 공개 페이지(catholic-shorts `talk-helper-privacy.html`)에 국외 이전 등 핵심 내용이 이미 있어서, 그 페이지에 새 기능(🚩 신고, 사용 기록, 모두 지우기)만 더했습니다(catholic-shorts PR #12). 이 초안은 판매판으로 바꿀 때 참고용으로 남겨 둡니다.

> 실제 공개 페이지는 예전 저장소 catholic-shorts 의 `talk-helper-privacy.html` 입니다 (플레이에 그 주소가 등록돼 있어 옮기지 않음).
> 이 초안 내용으로 그 페이지를 바꿔야 합니다.

시행일: 2026년 11월 ○일 · 운영자: 윤호요셉 · 문의: mernial@naver.com

「말로 답장」(이하 '앱')은 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」을 지킵니다. 앱은 따로 서버를 두지 않으며, 운영자는 이용자의 대화 내용을 받아 보거나 보관하지 않습니다.

## 1. 처리하는 정보와 목적

| 정보 | 언제 | 목적 | 어디에 |
|---|---|---|---|
| 말한 내용(음성을 글로 바꾼 것) | 🎤 버튼을 누르고 말할 때 | 답장 다듬기, 질문에 답하기 | Anthropic으로 전송(아래 3번) |
| 카카오톡 화면에 보이는 대화 글 | 🎤·🔎 버튼을 누른 순간 | 대화 흐름에 맞는 답장, 찾기 | Anthropic으로 전송, 휴대폰에 저장 안 함 |
| 이용자가 내보낸 카카오톡 대화(글·사진) | 이용자가 카카오톡 '대화 내용 내보내기'로 이 앱에 보낼 때 | 예전 대화에서 찾기 | **휴대폰 안에만 저장**. 찾을 때 질문과 관련된 글 부분만 Anthropic으로 전송. **사진은 전송하지 않음** |
| 내 이름·역할(선택) | 숨은 설정에 입력한 경우 | 호칭·말투를 맞추기 | 휴대폰 저장, 다듬기 요청에 함께 전송 |
| Claude API 키 | 설정할 때 | Claude 이용 | 휴대폰에만 저장 |
| 사용 기록(오류 기록) | 앱 사용 중 | 문제 해결 | 휴대폰에만 저장, 이용자가 직접 보낼 때만 전달 |

음성 자체는 휴대폰(구글)의 음성 인식 기능이 글로 바꾸며, 앱은 음성 파일을 저장하거나 보내지 않습니다.

## 2. 보관 기간과 삭제
- 휴대폰에 저장된 대화·사진은 이용자가 지울 때까지 보관됩니다. **앱 → 대화에서 찾기 → 이 대화 지우기**로 언제든 지울 수 있고, 앱을 삭제하면 모두 지워집니다.
- 운영자는 서버가 없어 이용자의 정보를 보관하지 않습니다.

## 3. 개인정보의 국외 이전 (처리 위탁)
| 항목 | 내용 |
|---|---|
| 받는 자 | Anthropic, PBC (privacy@anthropic.com) |
| 이전 국가 | 미국 |
| 이전 일시·방법 | 이용자가 🎤·🔎 버튼을 눌러 요청할 때마다, 암호화된 통신(HTTPS)으로 전송 |
| 이전 항목 | 말한 내용, 그 순간 화면의 대화 글, (찾기) 질문과 관련된 내보낸 대화 일부, 내 이름·역할(입력한 경우) |
| 목적 | 답장 문장 다듬기, 대화 내용 정리 |
| 보유 기간 | Anthropic의 API 데이터 정책에 따름 (안전 점검 목적 등으로 일정 기간 보관 후 삭제). AI 학습에는 쓰이지 않음 |

이용자는 국외 이전을 원하지 않으면 앱을 사용하지 않거나 삭제할 수 있습니다. 이 경우 답장 다듬기·찾기 기능을 쓸 수 없습니다.

## 4. 대화 상대의 정보
화면의 대화 글에는 대화 상대가 보낸 메시지가 들어 있을 수 있습니다. 앱은 이를 답장·찾기에만 쓰고 저장하지 않습니다. 이용자는 다른 사람의 민감한 정보가 담긴 대화에서는 사용을 삼가 주세요.

## 5. 접근성 권한
앱은 카카오톡 위에 버튼을 띄우고, 버튼을 누른 순간 카카오톡 화면의 글을 읽고, 이용자가 확인한 답장을 입력·전송하기 위해서만 접근성 권한을 씁니다. 카카오톡 이외의 앱 화면은 읽지 않습니다.

## 6. 제3자 제공·광고
앱은 개인정보를 판매하거나 광고에 쓰지 않으며, 3번 외에는 다른 곳에 제공하지 않습니다.

## 7. 만 14세 미만
앱은 만 18세 이상을 대상으로 하며, 만 14세 미만 아동의 정보를 알면서 처리하지 않습니다.

## 8. 이용자의 권리와 문의
이용자는 언제든 앱에서 정보를 지우거나 앱을 삭제할 수 있습니다. 문의·불편 신고: **mernial@naver.com** (개인정보 보호책임자: 윤호요셉)

## 9. 바뀌는 경우
이 방침이 바뀌면 이 페이지에 시행일과 함께 알립니다.
